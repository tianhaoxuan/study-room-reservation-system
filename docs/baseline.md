# 原始项目基线

## 当前技术栈

- Java 8
- Spring Boot 2.7.18
- MyBatis
- MySQL
- Maven
- JUnit 5 / Mockito

## 已实现功能

- 微信模拟登录
- 用户信息查询
- 楼栋、自习室和座位查询
- 创建及取消预约
- 我的预约分页查询
- 扫码签到和提前离座
- 超时未签到处理
- 违规记录和用户封禁
- 后台楼栋、房间、座位和配置管理
- Excel座位导入

## 已知问题

- 同座位并发预约可能重复成功
- 使用字符串判断时段冲突
- 座位物理状态与时段占用混用
- 超时任务全表扫描
- Token可以伪造
- 管理员接口没有鉴权
- 缺少真实数据库并发测试
